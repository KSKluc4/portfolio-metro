# Prints dos projetos

Coloque aqui os prints (PNG, JPG ou WebP) e aponte para eles no `config.js`:

```js
projects: {
  'pilates-studio': {
    image: 'assets/prints/pilates-studio.png',
  },
},
```

O print aparece no painel da estação, logo abaixo da placa. Uma largura de
1200 px já fica nítida; prefira arquivos com menos de 300 KB.
